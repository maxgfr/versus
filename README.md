# versus

Two-player mini-games for one phone, played face to face: red at the bottom, blue at the top. Also against the computer, or online between two phones. Free, offline, installable, no ads, no accounts, no tracking.

**Play:** https://maxgfr.github.io/versus/

Work in progress — the full game list, credits and privacy notes land with the first release.

## Develop

```sh
pnpm install
pnpm dev        # http://localhost:5173/versus/
pnpm verify     # typecheck, lint, tests, build, size budget
```
